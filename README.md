# ⚡ ENERGY KEEPER

**Energy Keeper** คือเกมแนว Incremental / Clicker ที่พัฒนาด้วย **C++** และ **SFML** ผู้เล่นจะต้องบริหารจัดการพลังงาน (Energy) ไม่ให้หมดลง รักษาระดับพลังงาน พร้อมอัปเกรดระบบเพื่อปลดล็อก Multiplier, Buffs และ Achievements ต่างๆ เพื่อก้าวสู่ความเป็นที่สุดแห่งการเก็บพลังงาน!

---

## 🇹🇭 ภาษาไทย (Thai)

### 🎮 ระบบเด่นภายในเกม

* **Energy Management**: พลังงานจะลดลงเรื่อยๆ ตลอดเวลา ต้องคอยกด Spacebar หรือคลิกเพื่อเติมพลังงานไม่ให้หมด
* **Upgrade System**: เพิ่มค่า Max Energy และรับ Multiplier เพิ่มขึ้นเมื่อ Level สูงขึ้น
* **Generator (Auto Energy)**: ซื้อระบบเจนพลังงานอัตโนมัติ ช่วยสร้างพลังงานให้อย่างต่อเนื่องโดยไม่ต้องเหนื่อยปั๊มเอง
* **Chest & Buffs**: สุ่มเปิดกล่องเพื่อรับสภาวะพิเศษ (Buffs) เช่น Infinite Energy หรือเร่งการสร้างพลังงาน
* **Achievements & Secret Codes**: ระบบเกียรติยศที่มอบ Multiplier เพิ่มเติม พร้อมการค้นหารหัสลับ (Easter Eggs) ภายในเกม
* **Custom Binary Save System**: ระบบบันทึกข้อมูลปลอดภัย ป้องกันการแก้ไขไฟล์เซฟด้วยโครงสร้างข้อมูลไบนารีเฉพาะ

### 🕹️ ปุ่มควบคุม (Controls)

* `SPACEBAR` / `Click`: เก็บพลังงาน (Collect Energy)
* `A`: เปิด/ปิด หน้าต่าง Achievements
* `S`: เปิดช่องกรอก Secret Code
* `M`: ปิด/เปิด เสียง (Mute BGM/SFX)
* `ESC`: พักเกม (Pause Menu)

### 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Language**: C++
* **Graphics & Audio**: SFML (Simple and Fast Multimedia Library)
* **Data Persistence**: Binary File Architecture with Custom Magic Header (`EKDB1`)

## 🇬🇧 English

### 🎮 Key Features

* **Energy Management**: Energy continuously depletes over time. Press Spacebar or click to sustain your energy levels.
* **Upgrade System**: Increase Max Energy capacity and boost your energy multiplier as your Level advances.
* **Automated Generators**: Purchase and upgrade Generators to automatically produce passive energy per second.
* **Chest & Buffs**: Unlock timed chests to claim powerful temporary buffs like Infinite Energy.
* **Achievements & Secret Codes**: Complete in-game milestones to acquire permanent Multipliers and discover hidden Easter Eggs.
* **Custom Binary Save System**: Secure save data architecture implemented via custom binary structures and unique magic headers (`EKDB1`).

### 🕹️ Controls

* `SPACEBAR` / `Click`: Collect Energy
* `A`: Toggle Achievements Menu
* `S`: Open Secret Code Prompt
* `M`: Toggle Audio (Mute / Unmute)
* `ESC`: Pause Game

### 🛠️ Tech Stack

* **Language**: C++
* **Graphics & Audio**: SFML (Simple and Fast Multimedia Library)
* **Data Persistence**: Custom Binary File Format (`EKDB1`)
